SkillScribe®

AI Interview Pipeline — from profile submission to detailed scorecard

Profile Submission Frontend
User submits GitHub & LinkedIn URLs via the landing page form. Optional metadata (name, role, experience) collected.
Data Ingestion Backend
Backend fetches GitHub repos, READMEs, languages. LinkedIn data scraped or provided as manual text. All stored in PostgreSQL.
Embedding Pipeline AI
Gemini Embedding API chunks & vector-embeds GitHub repos (summary + deep READMEs), languages, and LinkedIn profile. Stored in pgvector.
Question Generation AI
Gemini LLM generates tailored questions (technical, behavioral, project deep-dive, system design, coding) based on embedded profile context.
Interview Session Frontend
User answers one question at a time via text or audio recording. Progress tracked, skip available. Cmd+Enter to submit.
Answer Evaluation AI
Each answer sent to Gemini for scoring (0-100), structured feedback, strengths & weaknesses extraction. Score recorded in DB.
Results & Scorecard Frontend
User views overall score, per-category breakdown, per-question cards with feedback, strengths, weaknesses, and audio playback.
